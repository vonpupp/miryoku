#+TITLE: Printable Keymap (keymap-drawer)
#+AUTHOR: vonpupp
#+DATE: 2026-09-08

Printable keymap of the X.Tips V4s running stock Miryoku with our
=split_3x6_3_ex2= mapping. Files:

- =keymap.svg= / =keymap.png= — the printable diagrams (10 layers, one image)
- =keymap.yaml= — the [[https://github.com/caksoylar/keymap-drawer][keymap-drawer]]
  source; geometry comes straight from QMK via
  =layout: {qmk_keyboard: crkbd/rev4, layout_name: LAYOUT_split_3x6_3_ex2}=
  (the same setup as the well-known printable Corne v4.1 46-key maps)

* Regenerate

#+begin_src sh
pipx install keymap-drawer            # once
cd docs/
keymap draw keymap.yaml -o keymap.svg
rsvg-convert -w 1600 keymap.svg -o keymap.png
#+end_src

Or paste =keymap.yaml= into the web app at
https://caksoylar.github.io/keymap-drawer and download the SVG.

* Print

Open =keymap.png= (or =keymap.svg=) in a browser and print — scales cleanly
to A4.

* Geometry note (one known approximation)

The drawing uses crkbd/rev4's ex2 geometry, whose two inner extra keys per
half sit on the *top+home* rows. This board's extras sit one row lower
(*home+bottom*). The two DF keys are drawn on the crkbd extra slots; on the
physical keyboard they are the right inner *home* (QWERTY) and *bottom*
(Colemak) keys. Everything else matches 1:1.

* Legend conventions

- center = tap, bottom = hold (=A= + =Gui= = =LGUI_T(KC_A)=)
- =2× Boot= / =2× Base= / =2× Num= … = double-tap while holding a thumb key
  (Additional Features: bootloader, base-layer switching, layer locks)
- =DF QWERTY= / =DF Colemak= = instant default-layer switch on the extra keys
- dashed keys = physically present but unused in this mapping
