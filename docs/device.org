The daily keyboard: a 46-key split, bought fully assembled on AliExpress
(listing now dead; seller also on goofish, user id 137976734; the QR on the
PCB back resolves to =www.umux.com= → their goofish storefront).

* Identity

| Field        | Value                                        |
|--------------+----------------------------------------------|
| Product      | X.Tips V4s Keyboard (also sold as "V4a")     |
| Manufacturer | umux.com / X.Tips                            |
| USB          =  =5262:4e4b= (vendor 0x5262, product 0x4e4b)  |
| USB serial   | =vial:f64c2b3c= (Vial keyboard id, stock fw) |
| Key count    | 46 (23 per half)                             |
| Firmware     | QMK (Vial-capable; now stock Miryoku)        |

/Note:/ despite the "Corne V4" looks and marketing, this is NOT a foostan
Corne v4 (those are RP2040). It is a re-engineered clone with an STM32-family
MCU — verified by disassembly and by the bootloader it exposes.

* Microcontroller

| Field       | Value                                              |
|-------------+----------------------------------------------------|
| Chip        | Geehy APM32F103C8T6 (STM32F103C8 drop-in clone)    |
| Core        | ARM Cortex-M3                                      |
| Flash       | 64 KB (Miryoku build uses 51%)                     |
| RAM         | 20 KB                                              |
| Sibling rev | =v4s/072c= variant exists (STM32F072) — same USB ID |

* Bootloader

STM32duino / Maple DFU v1.0, serial "LLM 003". Enumerates as
=1eaf:0003 Leaflabs Maple DFU interface= with three alternate slots:

| Alt | Target                              | Use                          |
|-----+-------------------------------------+------------------------------|
| 0   | "ERROR. Upload to RAM not supported" | no — STALLs (=LIBUSB_ERROR_PIPE=) |
| 1   | Flash @ =0x8005000=                 | 32 KB-bootloader variant     |
| 2   | Flash @ =0x8002000=                 | **this board — use alt 2**   |

Entry methods:
- *Bootmagic*: hold =E= (left half) or =I= (right half) while plugging in
  USB (per-hand, from the vendor's config; matrix [0,3] / [4,3]).
- From running QMK firmware: a =QK_BOOT= keycode — in stock Miryoku, hold
  any thumb key and double-tap the top-row pinkie key on the same hand.

* Physical layout (46 keys, per half)

- 3 finger rows × 6 columns + 3 thumb keys (standard Corne shape).
- *2 extra keys per half* on the innermost column at the **home and bottom**
  rows (NOT top+home like the official Corne v4 / =crkbd/rev4_0= ex2 —
  one row lower). Row counts per half: 6 / 7 / 7 + 3 thumbs.
- Direct-pin wiring (one GPIO per key, no diode matrix).
- Optional rotary encoder on the right half (=C14= / =C15=, res 4).

Current mapping (our fork): miryoku on the inner 5 columns per hand; outer
columns and the left inner extras unused; right inner home = =DF(U_EXTRA)=
(QWERTY), right inner bottom = =DF(U_BASE)= (Colemak).

* Matrix / pins (from the vendor's keyboard.json)

Left half (rows 0-3, cols 0-6):

#+begin_example
row0: B12 B15 A8  B3  B4  B5  —
row1: B11 B13 B14 A15 B8  B9  C13
row2: B1  B0  A4  C15 A0  A1  C14
row3: —   —   —   A3  A7  A2  —
#+end_example

Right half (=split.matrix_pins.right.direct=, mapped to matrix rows 4-7):

#+begin_example
row4: —   B13 B15 A8  A15 B3  B4
row5: B11 B10 B12 B14 B5  B8  B9
row6: B2  B1  B0  A4  A0  A1  C13
row7: —   A7  A6  A3  —   —   —
#+end_example

Split link: soft serial on =B6=. Thumbs: left =A3 A7 A2= (x3..x5), right
=A7 A6 A3= at =B10..B12= positions (matrix [3,3..5] / [7,1..3]).
