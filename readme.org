[[https://github.com/manna-harbour/miryoku/][Miryoku]] is an ergonomic, minimal, orthogonal, and universal keyboard layout.


** About this fork

Personal mirror of the Miryoku project, centred on porting it to my keyboard:
the 46-key X.Tips V4s split (STM32F103, see [[file:docs/device.org][docs/device.org]]).
Everything lives on the branch =miryoku-LAYOUT_split_3x6_3_ex2= in each repo
(same name everywhere).

- Phase 1 complete and hardware-accepted (2026-09-08): stock Miryoku on the
  V4s with =DF= base-layer switching (QWERTY/Colemak) on the right inner
  extra keys. Design and history: [[file:docs/superpowers/specs/2026-09-07-miryoku-split-3x6-3-ex2-design.md][spec]],
  [[file:docs/superpowers/plans/2026-09-07-miryoku-split-3x6-3-ex2.md][plan]].
- Device docs: [[file:docs/device.org][device]] · [[file:docs/flashing.org][flashing]] ·
  [[file:docs/printable-keymap.org][printable keymap]]

** Roadmap

- Alternative alpha layout support in babel: Gallium (done 2026-09-08),
  Sturdy, Magic Sturdy, Canary
  ([[https://getreuer.info/posts/keyboards/alt-layouts/index.html][Pascal Getreuer's alternative layouts list]]).
- Layer tweaks from the pre-Miryoku Vial config (home-row tap-dance mods
  equivalents, mouse-layer row order) — see the spec's future-phases notes.
